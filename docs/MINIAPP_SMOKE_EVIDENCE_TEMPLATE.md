# Miniapp Smoke Evidence Template

Use one completed copy of this template for every pull request that changes a
user-visible miniapp flow. Keep the completed record in the pull request or
the agreed QA evidence location; do not put real credentials, phone numbers,
openid values, salary values, or production screenshots in this template.
