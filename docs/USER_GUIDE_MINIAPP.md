# LaborFlow 小程序现场端操作手册

## 1. 用途与前提

本手册描述当前小程序的现场填报、工资查询、待办和个人资料路径。它不代表真实账号、
弱网或真机流程已经通过上线验收；这些场景仍由最终 Gate 记录决定。范围和延期事项以
[`LAUNCH_SCOPE.md`](LAUNCH_SCOPE.md) 为准，角色范围以
[`ROLE_PERMISSION_MATRIX.md`](ROLE_PERMISSION_MATRIX.md) 为准。

登录前，管理员应在 Web 后台为测试账号配置角色、员工绑定与项目成员关系。测试账号
必须使用非生产数据；不要截取或保存密码、token、openid、真实工资或个人资料。

## 2. 首页与导航

登录成功后进入“首页”。底部标签依次为“首页、工资、现场、待办、我的”：

- 首页显示角色、员工绑定状态、今日日报、待办、草稿和需修改数量，以及最近工资和在建
  项目。
- “填报日报”“签证上报”“现场照片”进入现场填报；“查看全部”进入“现场”页签。
- “现场”按日报/签证、状态、关键字或日期分页查询，支持下拉刷新和继续加载。
- “工资”只展示当前绑定员工本人的工资记录；未绑定员工时会显示不可用提示。
- “待办”仅对具备管理权限的角色开放；无审批权限时会明确提示。
- “我的”显示账号、员工和角色信息，可刷新资料或退出登录。

首次使用或角色、绑定关系变更后，进入“我的”选择“刷新资料”，再回到首页下拉刷新。

## 3. EMPLOYEE：工资查询与现场填报

### 3.1 查看本人工资

1. 打开“工资”，确认页面显示的是本人绑定员工。
2. 查看工资月份、应发、扣减、实发、发放状态和工资条确认状态。
3. 点击记录进入工资详情，按页面提供的入口确认工资条或提交反馈。

仅本人绑定工资可见。未绑定、空记录或加载失败时，按页面提示处理，不应使用其他账号
代替查看。

### 3.2 填报日报

1. 从首页选择“填报日报”，或在“现场 > 日报”中新增。
2. 选择有权限的项目、施工段、工序和必要的合同清单，填写日期、数量及说明；页面会
   预览价格来源、单价和预计产值。多个匹配清单时必须人工选择。
3. 没有有效价格时可保存为“未定价”草稿，但不能提交；由项目管理人员补齐价格后重新
   打开详情并预览。
4. 可先保存草稿，确认字段与附件后再提交。提交中请等待页面结果，不要反复点击。
5. 被驳回的日报回到列表后修改，再提交；项目、施工段或工序无法加载时，先重试或联系
   项目管理人员核对项目成员关系。

日报的本机草稿以当前用户为范围保存。保存、上传或提交失败时，页面会尽量保留已填写
内容和已成功上传的部分附件；网络恢复后可继续添加附件或再次保存。成功提交后，确认
草稿已清除再离开页面。

### 3.3 填报签证

1. 从首页选择“签证上报”，或在签证列表中新增。
2. 选择授权项目和施工段，选择签证类型，填写发生日期、原因和金额等必填信息。
3. 可拍摄或从相册选择现场照片，最多六张。上传部分失败时，已成功的照片会保留，处理
   网络问题后再继续添加。
4. 保存草稿或提交前核对项目、施工段、类型、金额和附件归属。提交成功后回到列表查看
   状态；被驳回时按意见修改。

签证本机草稿同样按当前用户隔离。草稿或驳回状态可按页面入口增删服务器附件；提交或
确认后的证据附件不可修改。详情会分别显示预估金额与最终确认金额。

## 4. MANAGER、BOSS 与 FINANCE：待办处理

具备管理权限的账号通过统一待办接口只看到本角色和项目范围允许处理的事项：

- MANAGER 可以处理日报、签证和班组结算待办。
- FINANCE 只处理班组结算待办，不处理工资审核、日报确认或签证确认。
- BOSS 的小程序角色展示与实际待办范围应以当前服务端返回和权限矩阵为准；工资审核的
  正式操作路径在桌面管理端。
- ADMIN 不应用小程序代替桌面端的用户、角色、微信绑定和审计管理。

处理待办时一次只打开一项，先进入对应工资、日报、签证或结算完整详情，核对项目、人员、
定价/金额、附件与审批历史。选择“同意”或“驳回”后补充意见；签证同意必须输入非负的
确认金额。按钮提交期间会锁定，完成后刷新列表确认该事项已消失或状态已更新。

## 5. 个人资料、退出与异常

- “我的”显示当前账号的绑定和角色。账号未绑定员工时，工资查询不可用，应由管理员在
  Web 后台维护绑定关系。
- 选择“退出登录”会清理本机登录状态；多人共用设备时，完成后必须退出。
- 页面加载失败时使用页面的“重试”或下拉刷新，不要把失败状态当作空数据。
- 登录失效、权限不足、上传不完整、重复提交、工资确认或待办异常，应记录页面、角色、
  测试数据标识、网络条件和实际提示，并按
  [`LAUNCH_DEFECT_POLICY.md`](LAUNCH_DEFECT_POLICY.md) 提交问题。

## 6. 上线验收提醒

真实账号登录、日报和签证上传、待办审批、工资确认、弱网恢复以及截图/录屏证据，目前
仍是正式上线审查的阻断 Gate。执行人员必须按 [`UAT_CHECKLIST.md`](UAT_CHECKLIST.md) 完成
真实流程并在最终签字记录中留痕，或取得正式范围延期批准；在此之前不得把本手册当作
上述场景已经验收通过的证明。
